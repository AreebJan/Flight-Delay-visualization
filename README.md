# Flight Delay Dashboard

An interactive dashboard built with Python, Dash, and Plotly to visualize airline flight delay statistics across the United States.

## Overview

This project allows users to explore different types of airline delays by year using interactive visualizations. The dashboard dynamically updates based on the selected year and displays trends for multiple airlines.

The dashboard includes visualizations for:

- Carrier delays
- Weather delays
- NAS (National Aviation System) delays
- Security delays
- Late aircraft delays

## Features

- Interactive dashboard built with Dash
- Dynamic year filtering
- Multiple responsive Plotly line charts
- Clean and modern dashboard UI
- Real airline delay dataset
- Data processing with pandas

## Libraries Used

- Python
- pandas
- Dash
- Plotly Express

## Dataset

The dataset contains airline delay information including:

- Delay categories
- Reporting airlines
- Monthly statistics
- Flight delay durations

Dataset source:
IBM Developer Skills Network Airline Dataset

## Installation

Clone the repository:

```bash
git clone https://github.com/AreebJan/flight-delay-dashboard.git
cd flight-delay-dashboard
```

Install dependencies:

```bash
pip install pandas dash plotly
```

Run the application:

```bash
python app.py
```

Open the dashboard in your browser:

```bash
http://127.0.0.1:8050/
```
